download_for_offline How to Run & Install the Application

1
Install Directly on Android Phones / Tablets:

Click Download APK (28 MB). Once downloaded, open the file on your device and tap Install. The app works 100% offline with pre-seeded data, with optional Google Cloud Sync.

2
Open the Full Project in Android Studio:

Click Download Project ZIP (27 MB) and extract it. In Android Studio, click File > Open and select the extracted folder. All Gradle scripts, dependencies, Room Database, and Compose UI files are fully pre-configured.

3
Desktop & Mobile Dual Layouts:

The app automatically adapts to widescreen tablets/desktop browsers with a side Navigation Rail and multi-pane cards. You can also toggle between Desktop Site and Mobile view using the toggle button in the top app bar.
